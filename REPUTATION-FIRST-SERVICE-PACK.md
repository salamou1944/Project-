# Reputation-First Service Pack

## Purpose
Use a small, auditable paid pilot to turn existing technical capability into the first real customer proof. These are portfolio demonstrations, not prior client case studies.

## Service A — Lead Intake Reliability Pilot
**Problem:** leads arrive through forms/webhooks and are duplicated, malformed, misrouted, or silently lost.

**Pilot delivery:**
- webhook/form intake
- schema validation and normalization
- deterministic duplicate check
- routing decision
- notification/human-review path
- explicit failure path
- retry/replay notes
- acceptance tests
- short handover document

**Customer outcome:** every test submission produces a traceable accepted/rejected/review result instead of an opaque workflow failure.

## Service B — CRM/API Synchronization Repair
**Problem:** CRM and external API records drift or create duplicates.

**Pilot delivery:**
- field mapping
- input validation
- idempotency key / submission identity
- API response validation
- retry/error path
- audit log
- replay procedure

## Service C — AI Intake with Human Gate
**Problem:** incoming email/form data needs extraction/classification before entering a CRM.

**Pilot delivery:**
- input capture
- structured extraction
- schema validation
- business-rule validation
- human-review gate for ambiguous output
- CRM/webhook handoff
- failure evidence

AI output is never treated as success without validation.

## Proof rules
- Synthetic/demo data is labelled synthetic.
- Personal/portfolio builds are never described as client work.
- No claim of production experience without evidence.
- No customer, revenue, testimonial, or deployment is counted without external evidence.
