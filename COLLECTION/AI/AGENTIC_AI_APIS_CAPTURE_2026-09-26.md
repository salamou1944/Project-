## Important extraction rule

Do NOT import all 3,024 entries into the Operator as executable capabilities.

The catalog is a discovery source. Each candidate must pass:
DISCOVERY -> source inspection -> license/terms check -> API/docs inspection -> dependency check -> cost/quota/geography check -> security review -> adapter contract -> runtime reachability -> operation test -> independent verification -> promotion.

## Cost-control rule

The source is especially valuable for the user's goal of reducing subscriptions, but:
- free/open-source != free hosted API
- free tier != unlimited
- API listed != API available to our account
- provider existence != geographic availability
- advertised capability != verified runtime capability

No provider is integrated merely because it appears here.

## Security rule

Reject candidates that require credential extraction, auth bypass, CAPTCHA/MFA bypass, unrestricted host access, or unsafe persistence. Browser/computer-use and scraping candidates remain permission-bound and target-scoped.
