# Sherlock — COLLECTION capture

Source: https://github.com/sherlock-project/sherlock
Project: sherlock-project/sherlock
License: MIT
Purpose: username enumeration across 400+ social networks for OSINT/reconnaissance.

## Verified source snapshot
- Official README documents CLI usage for one or multiple usernames.
- Current documented release/version in the README: 0.16.0.
- Supported output formats include TXT, CSV, XLSX and JSON.
- Supports site-scoped searches, timeout control, local data, proxies, and found/all result output.
- Official project describes the tool as a username finder across 400+ social networks.

## Collection role
Sherlock is a discovery/enumeration component, not an identity-proof component.
Pipeline:
ACCOUNT/USERNAME CANDIDATE
→ Sherlock discovery
→ URL/status normalization
→ false-positive review
→ source/account verification
→ provenance record
→ downstream account expansion

## Integration rule
Do not treat a Sherlock hit as verified identity. A hit means only that the configured Sherlock detector reported a matching username at a target site. Verification requires a second source or direct inspection appropriate to the authorized collection task.

## Security / operational constraints
- Use only for authorized OSINT and owned/authorized collection targets.
- Do not collect credentials, secrets, private data, or bypass access controls.
- Keep the executable path configurable; do not silently install dependencies in production.
- Apply explicit timeouts and fail closed on malformed output.
- Preserve the original username and source URL for provenance.
- Discovery results must remain distinct from verified account records.

## Implementation target
Use Sherlock as an optional provider-neutral username-discovery adapter in Salamou-31/API Factory. The adapter must:
1. validate username inputs;
2. invoke a locally installed Sherlock executable only;
3. enforce a bounded timeout;
4. parse found URLs deterministically;
5. return structured discovery evidence;
6. never claim identity verification;
7. remain usable without Sherlock installed so the rest of API Factory tests still pass.

## Implementation result in Salamou-31
- Adapter: AI-API-HUB/api-factory/sherlock-username.mjs
- Endpoint: POST /v1/factory/research/username
- CI installs the official sherlock-project package and verifies its version before API Factory tests.
- Request cannot choose an arbitrary executable path; the runtime uses SHERLOCK_BIN from trusted environment configuration.
- Discovery evidence remains explicitly unverified.
- Production/runtime execution is not marked verified until the corresponding GitHub Actions run reports success.
