## Verified implementation patterns
- Unified MCP surface over multiple backends.
- Typed structured outputs via outputSchema/structuredContent.
- Model registry with verified vs inferred confidence.
- recommend_model for local model selection.
- validate_params before spending a generation.
- preflight_check for auth/reachability before execution.
- Retry with exponential backoff + jitter and Retry-After handling.
- Circuit breaker.
- Idempotency keys held across retries.
- Structured backend error taxonomy.
- Backend adapter boundary and dependency-injection seams.
- Test/lint/type-check quality gates.

## Reuse decision
REUSE_PATTERNS_ONLY.

Do not copy the experimental consumer web-backend/reverse-engineering path into production systems. The repository itself warns that this backend is private/undocumented, subject to schema drift and likely unsupported by the service terms. Prefer official/public APIs and preserve explicit provider boundaries.
